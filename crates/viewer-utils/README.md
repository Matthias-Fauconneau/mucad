# µcad Viewer Utilities

[![Crates.io](https://img.shields.io/crates/v/mucad-viewer-utils.svg)](https://crates.io/crates/mucad-viewer-utils)
[![Documentation](https://docs.rs/mucad-viewer-utils/badge.svg)](https://docs.rs/mucad-viewer-utils/)

This crate provides utilities shared by the µcad viewers, independent of a renderer: the
[Bevy viewer](https://crates.io/crates/mucad-viewer) and the web viewer, via
[mucad-wasm](https://crates.io/crates/mucad-wasm).
