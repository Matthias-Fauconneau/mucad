µcad viewer demo

<mucad-viewer> shows µcad models in a page, e.g. in the documentation. Each viewer compiles its code, when it is scrolled to. 

<script type="module" src="mucad-viewer.js"></script>

Code in the element

<mucad-viewer>std::geo3d::Torus([1..5] * 10mm, minor_radius = 3mm);</mucad-viewer>
std::geo3d::Torus([1..5] * 10mm, minor_radius = 3mm);

<mucad-viewer src="heart.mu"></mucad-viewer>
