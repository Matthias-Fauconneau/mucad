# µcad editor integrations

This folder contains integrations and plugins for various editors and IDEs.

- [`vscode`](vscode): Visual Studio Code extension
- [`zed`](zed): Zed extension
- [`tree-sitter-mucad`](tree-sitter-mucad): tree-sitter grammar with highlight queries, e.g. for Zed
- [`web-components`](web-components): code editor, model viewer and the µcad editor app, e.g.
  `<mucad-viewer>` for the documentation
- [`web-viewer`](web-viewer): web app to edit, display and export µcad models in a browser
- [`desktop`](desktop): desktop app with the editor of the web viewer, made with Tauri
